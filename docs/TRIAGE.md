# Email v1 host contract

The package has no classifier, profile UI or paid AI dependency. After filtering/preparing all eligible files and redacting Markdown through ConnectorIngestionContract, it emits `Event::dispatch('askmydocs.email.prepared.v1', [$envelope])` synchronously. An ordinary Laravel listener validates and durably registers it before returning. If the listener fails, no source is written and the pending message remains unacknowledged.

Envelope: schema_version=1, explicit tenant_id/installation_id/project_key, body metadata, email_date and ordered manifest. Metadata has connector/provider/mailbox/native-message IDs, compound email_message_key, label IDs/names, attachment count, body SHA256 and semantic revision SHA256. Each manifest slot commits native file ID/name/MIME/content hash or explicit exclusion reason. Slot ordering is case-sensitive native identity order; filenames do not identify receipts. All attachment receipts carry the same parent hashes/key plus email_attachment_id/email_attachment_slot/email_attachment_hash and legacy linking fields.

AskMyDocs's shared adapter offers opt-in profiles/assistant, immutable body/attachment snapshots, readiness gating, semantic decision deduplication, retries/outbox/costs, campaigns, tags, ACL and versioning to both Gmail and Microsoft Mail while preserving IMAP signatures/keys. Another consumer without a listener can ingest normally but cannot claim those triage semantics. See [STANDARD.md](specs/2026-10-14-email-api/STANDARD.md) for the frozen hashing algorithm and all acceptance conditions.
